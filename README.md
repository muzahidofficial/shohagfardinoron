# Shohag Fardin Oron — Signature Portfolio

A polished, responsive multi-page personal-brand website built from the supplied portfolio brief and real photography.

## Pages
- `index.html` — Home
- `about.html` — About
- `expertise.html` — Expertise
- `speaking.html` — Speaking
- `impact.html` — Impact
- `insights.html` — Insights
- `book.html` — 1:1 Session + Enquiry
- `404.html` — Custom not-found page

## Final polish included
- Floating glass navigation with active-page states and mobile menu.
- Immersive light-to-dark hero with real speaking photography and formal foreground portrait.
- Real photography across every page, including responsive galleries and editorial photo sections.
- Full mobile/tablet hardening from small phones through desktop.
- Accessible keyboard navigation, skip link, focus states, reduced-motion support and semantic current-page states.
- Image width/height metadata, lazy loading, async decoding and high-priority loading for the main hero portrait.
- Image lightbox for portfolio photography.
- Scroll progress indicator and back-to-top control.
- CTA query routing so Speaking / Career / Personal Branding links preselect the correct enquiry type.
- Improved Insights page with real editorial directions instead of placeholder article titles.
- Removed dead `#` social/Careers Up placeholder links from the public UI.
- Basic Open Graph metadata, robots metadata and Person structured data on the homepage.
- Custom 404 page.
